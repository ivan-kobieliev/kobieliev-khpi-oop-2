# Лабораторна робота №3

### Варіант №6
Реєстрація заявок на ремонт техніки

---

## Опис роботи

У роботі реалізовано модульне тестування застосунку для системи реєстрації заявок на ремонт техніки.

Створено класи:
- Client
- Device
- Main
- RepairRecord
- RepairRequest
- ServiceCenter
- Technician

Реалізовано тестові класи:
- ClientTest
- RepairRequestTest
- ServiceCenterTest

Проведено тестування коректності роботи класів, обробки помилок та зміни стану об'єктів.
