# Лабораторна робота №12

### Варіант №6
Система бронювання

---

## Опис роботи

У роботі реалізовано консольний Java-застосунок для роботи з Stream API та функціональними операціями над колекціями.

Створено класи предметної області:
- Customer;
- Room;
- Reservation;
- ReservationStatus;

Також реалізовано сервісний клас:
- ReservationAnalytics;

У роботі використано Stream API:
- filter();
- map();
- sorted();
- count();
- collect();
- toList();
- groupingBy();
- summarizingDouble();

Реалізовані операції:
- пошук бронювань за діапазоном дат;
- сортування бронювань;
- пошук за типом кімнати;
- підрахунок бронювань за статусом;
- групування бронювань;
- обчислення загального доходу;
- статистика цін бронювань;
- генерація текстового звіту;

Також створено:
- Main — демонстраційна програма;
- ReservationAnalyticsTest — модульні тести;

---

## Stream API

У роботі використано:

### filter()

Використовується для:
- пошуку бронювань за датами;
- фільтрації за статусом;
- пошуку за типом кімнати;

### map()

Використовується для:
- перетворення об’єктів бронювання в список імен клієнтів;

### sorted()

Використовується для:
- сортування бронювань за датою;
- сортування за вартістю бронювання;

### collect()

Використовується для:
- групування бронювань;
- підрахунку статистики;
- формування колекцій;

### toList()

Використовується для:
- перетворення Stream у List;
