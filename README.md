# Lab 08: Files. Exceptions. Serialization

## Variant
Номер 6: Система планування подорожей

This project demonstrates file I/O, object serialization, and custom exception handling in Java.

Domain:

- HotelBooking  
- TrainTicket  
- MuseumPass  
- TravelPlan  

Implemented features:

- in-memory storage of travel items  
- text export/import using a delimiter-based format (`;`)  
- binary serialization/deserialization of the whole TravelPlan  
- custom domain validation via InvalidTravelDataException  
- JUnit tests for core behavior and persistence
