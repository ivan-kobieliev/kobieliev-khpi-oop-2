# REPORT.md

## Variant
- тема: Система бронювання
- номер: 6

## Model overview
У роботі реалізовано класи:

- Customer — описує клієнта системи бронювання;
- Room — описує кімнату готелю;
- Reservation — описує бронювання;
- ReservationStatus — перелік статусів бронювання;
- ReservationAnalytics — сервісний клас для аналізу даних через Stream API.

## Stream API usage
У роботі використано Stream API для обробки колекцій бронювань.

Реалізовано:
- фільтрацію бронювань за датами;
- пошук за типом кімнати;
- сортування бронювань;
- підрахунок кількості бронювань;
- групування бронювань за статусом;
- статистику цін;
- обчислення загального доходу;
- генерацію текстового звіту.

## Stream operations
У роботі використано:
- `filter()`
- `map()`
- `sorted()`
- `count()`
- `collect()`
- `toList()`
- `groupingBy()`
- `summarizingDouble()`

Також продемонстровано різницю між:
- imperative-підходом;
- stream-підходом.

## Demo scenario

У класі Main продемонстровано:
- створення тестових бронювань;
- роботу Stream API над колекціями;
- сортування та фільтрацію;
- групування даних;
- статистику цін;
- пошук найдорожчого бронювання;
- побудову текстового звіту;
- порівняння imperative та stream підходів.
