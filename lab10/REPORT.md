# REPORT.md

## Variant
- тема: Інтернет-магазин
- номер: 6

## Model overview
У роботі реалізовано класи:

- Product — описує товар магазину;
- CartItem — описує елемент кошика;
- Order — описує замовлення;
- StoreContainer<T> — узагальнений контейнер для зберігання об’єктів;
- StoreContainerIterator — внутрішній ітератор контейнера.

## Generic container
У роботі реалізовано власний generic-контейнер `StoreContainer<T>`.

Контейнер підтримує:
- додавання елементів;
- отримання елементів за індексом;
- видалення елементів;
- автоматичне розширення внутрішнього масиву;
- перевірку розміру та порожності контейнера.

Для зберігання даних використовується внутрішній масив типу `T[]`.

## Demo scenario
У класі Main продемонстровано:
- роботу generic-контейнера з типом `CartItem`;
- використання контейнера з типом `String`;
- обхід через `Iterator`;
- обхід через `for-each`;
- додавання та видалення елементів.
